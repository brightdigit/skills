# skills

BrightDigit's agent skills. Install them with the [skills](https://github.com/vercel-labs/skills) CLI, which records them in `skills-lock.json`:

```sh
npx skills add brightdigit/skills
```

| Skill | Use it for |
| --- | --- |
| [mac-app-screenshots](skills/mac-app-screenshots/SKILL.md) | Automated website and App Store screenshots for macOS apps with [GrabKit](https://github.com/brightdigit/GrabKit) |
